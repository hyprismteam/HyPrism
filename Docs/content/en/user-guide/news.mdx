# News reader

The native news page fetches the Hytale feed and renders full articles inside the launcher

## Layout

Wide windows use two columns with the feed on the left and the selected article on the right. Compact windows show the feed and article as separate pages with a back action

Article content supports headings, paragraphs, links, images, inline and block code, quotes, nested lists, and collapsible sections. External links open in the system browser

## Caching

Feed metadata, parsed articles, and remote images are cached so repeated visits avoid unnecessary network and parsing work. A skeleton is shown only while uncached content is being prepared

Use **Load more** at the end of the feed to request older entries
