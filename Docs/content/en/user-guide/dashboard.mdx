# Home

Home is the native launch surface. It presents the selected instance over the configured background and keeps launch preparation in one focused place

When no instance exists, Home welcomes the player, explains the next step, and offers a direct action to create the first instance. When an instance is selected, Home shows its branch and version with links to play, download, or manage it

After an installation completes, HyPrism always starts the game automatically

The background can rotate automatically or use a specific image from **Settings → Appearance**
