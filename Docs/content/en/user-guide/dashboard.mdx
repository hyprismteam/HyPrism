# Dashboard

The dashboard is the native launch surface. It shows the selected instance over the configured background and keeps the main action in the center of the page

When no instance is selected, the dashboard asks you to choose one. When an instance is available, the launch coordinator resolves its version, downloads missing data, prepares authentication and assets, then starts the game process

The background can rotate automatically or use a specific image from **Settings → Appearance**
