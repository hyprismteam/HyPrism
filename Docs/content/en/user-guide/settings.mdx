# Settings

Settings use the same adaptive master-detail layout as the news reader. Wide windows keep categories beside their content and constrain the selected page to a centered readable column. Compact windows show one page at a time, use the available width, and support the Back button or Escape

## Categories

| Category | Purpose |
| --- | --- |
| General | language, music, launch behavior, announcements, and news visibility |
| Downloads | official and community download sources |
| Java | bundled or custom runtime, initial memory, maximum memory, and extra arguments |
| Appearance | background selection and interface personalization |
| Network | connected or autonomous authentication for local profiles |
| Graphics | preferred GPU for game launch |
| Variables | environment variables passed to the game process |
| Data | application and instance storage locations |
| About | project and license information |

Java heap arguments such as `-Xms` and `-Xmx` are managed by the memory controls and are rejected in the free-form arguments field

## Local profile authentication

Connected mode requests a session from the configured authentication service and keeps its account-data integration available. Autonomous mode starts a dedicated Local Node process on `https://h.localhost:8443`, creates an ephemeral OmniAuth identity, and redirects the client service endpoints to that node

Local Node attaches to the game process after launch. Closing HyPrism does not interrupt an active autonomous game session, and the node exits automatically when the game closes. Its isolated diagnostics are stored beside the launcher and instance logs in the current `Logs/<launch-time>/` directory

Both modes use the DualAuth Agent for the embedded server. HyPrism no longer modifies `HytaleServer.jar`. Installations left by an older release are restored from their backup before launch

The Local Node persists profiles, saved skins, and presence preferences on the device. It unlocks all character creator items found in the active instance's `Assets.zip`, while cosmetic choices remain local. Centralized friends, parties, invites, global presence, cloud cosmetic synchronization, and server discovery return compatible empty states because there is no shared backend. Direct friend joins still depend on a reachable host through LAN, UPnP, IPv6, port forwarding, or a VPN such as Tailscale

## Download sources

The Downloads page shows the official Hytale source and community mirrors in one table under **Download sources**. Its columns show the endpoint link, source type, current availability, and enabled state. Availability starts with a spinner that smoothly changes to a check or cross when the background probe finishes. HyPrism continues measuring source latency for automatic source selection without displaying ping in the table. A connected Hytale account is required for the official source

Selecting **Add** opens a wizard. Its first step lets you enter a public HTTPS address for automatic format detection or paste a complete `.mirror.json` definition manually. HyPrism validates either result before saving the source

Each user-provided source can be enabled or disabled from the table. Its three-dot action menu contains source-specific actions, including removal with confirmation. HyPrism prioritizes the official download source and automatically selects the fastest added user mirror when the official source is unavailable

Only add sources you trust. Automatic mode only requests the public address, while manual JSON mode accepts the complete source definition, including optional custom headers

The About page shows the installed launcher version, the latest commit in `main`, project and community links, the core team, an adaptive row of recent contributors, the source-code license, the Hytale EULA, visual credits, and the disclaimer. Visual credits separate illustrations provided by Icons8 from animated media provided by Lordicon, with the required Lordicon link on its row

Settings are written through `IDesktopSettingsStore` and persisted by `IConfigStore`
