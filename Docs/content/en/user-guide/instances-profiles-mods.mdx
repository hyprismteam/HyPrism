# Instances, profiles, and mods

The Core contains the working domain logic for all three areas. The native instance manager is available, while profile and mod pages are still being completed

## Instances

The native instance manager lists local installations, highlights the active instance, and creates an installation target by selecting a release channel and available version. It uses a two-column layout in wide windows and a stacked one-column layout when space is limited. With no instances, the list pane is removed so the create action has the full page

When no instances exist, the page starts with the first step of an instance wizard. Selecting **Select version** uses a phased transition that removes the first step before showing a configuration screen with a wrench icon, title, explanation, branch switch, and version picker. The branch switch uses a light gray sliding selection. The version picker shows a spinner only while uncached data is loading. Switching to a branch with fresh cached versions updates the picker immediately without another catalog request. Creating an instance does not download game files immediately. Select it and use the main action to download or launch it

Core can also migrate legacy layouts, change versions, import ZIP archives, and delete installations

## Profiles

Core supports offline and official profiles, stable profile identifiers, per-profile data, identity switching, avatar backups, skin recovery, and authentication session storage

The complete profile list is stored in `Profiles/profiles.json`. `config.json` contains only `SelectedProfileId`, so creating, selecting, renaming, and deleting a profile always changes the multi-profile store instead of a second launcher identity

Launching requires an existing selected profile with a valid name and UUID. HyPrism does not silently create an identity during launch

## Mods

Core integrates with CurseForge for search, categories, file resolution, installation, local file import, changelogs, and update checks scoped to an instance

The native profile and mod pages are still being built. Historical interaction behavior can be inspected in version control when it is useful
