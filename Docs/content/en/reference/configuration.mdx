# Configuration reference

`JsonConfigStore` loads and saves the `Config` model as `config.json`

## Identity and selection

| Key | Meaning |
| --- | --- |
| `SelectedProfileId` | stable active profile identifier |
| `SelectedInstanceId` | stable active instance identifier |
| `OnlineMode` | use the configured connected authentication service for a local profile; when disabled, start the Local Node and use its OmniAuth session |
| `AuthDomain` | connected authentication service used for sessions and account data |

## Launch and Java

| Key | Meaning |
| --- | --- |
| `CloseAfterLaunch` | close HyPrism after a successful game start |
| `LaunchAfterDownload` | launch automatically after installation completes |
| `UseCustomJava` | select a user-provided Java executable |
| `CustomJavaPath` | absolute path to that executable |
| `JavaArguments` | extra JVM options and managed heap arguments |
| `GpuPreference` | `dedicated`, `integrated`, or `auto` |
| `GameEnvironmentVariables` | newline-separated `KEY=VALUE` entries |

## Interface and data

| Key | Meaning |
| --- | --- |
| `Language` | culture code such as `en-US` or `ru-RU` |
| `MusicEnabled` | background music state |
| `BackgroundMode` | `auto` or a bundled background file name |
| `DisableNews` | skip news retrieval and presentation |
| `ShowDiscordAnnouncements` | show supported announcements |
| `DismissedAnnouncementIds` | announcement identifiers hidden by the user |
| `InstanceDirectory` | custom instance root |
| `ShowAlphaMods` | include alpha mod files in search results |

Profile names, UUIDs, and the profile list are not stored in `config.json`. They live in `Profiles/profiles.json`, while profile-scoped files live in `Profiles/<profile-id>/`

On first load of an older configuration, HyPrism moves `Nick`, `UUID`, embedded `Profiles`, and `ActiveProfileIndex` into the profile store and removes those keys from `config.json`. Runtime code only uses `SelectedProfileId`

The Local Node hostname and port are intentionally fixed at `h.localhost:8443` because the client patch depends on the exact 16-character replacement. They are not stored in `config.json`
