# Installation

## Release builds

Download the build for your platform from [GitHub Releases](https://github.com/hyprismteam/HyPrism/releases)

| Platform | Current target | Common packages |
| --- | --- | --- |
| Windows | x64 | portable ZIP |
| Linux | x64 | tar.xz |
| macOS | Apple Silicon | DMG |

Release packages contain the native Avalonia Desktop application and the Local Node apphost required for offline authentication

## Run the native desktop project

Install the .NET 10 SDK, clone the repository, then run

```bash
dotnet restore HyPrism.sln
dotnet run --project Sources/HyPrism.Desktop/HyPrism.Desktop.csproj
```

The desktop project references `HyPrism.Core` directly and does not require Node.js

## Local data

HyPrism resolves its writable application directory at runtime. Configuration, profiles, instances, caches, logs, mirrors, and downloaded support tools are stored below that directory

Back up the application directory before testing migration code against an existing installation
