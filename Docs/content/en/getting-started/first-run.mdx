# First run

On startup, HyPrism presents a solid-color loading screen arranged like the successful official-account callback page. A compact looping Lottie animation with an opacity mask occupies the central status area, theme-accent progress dots accompany the current operation, and the launcher logo remains at the bottom. During this time HyPrism creates its application directory, loads `config.json`, migrates supported legacy data, registers the services required by the desktop host, and preloads the Hytale news feed, previews, team avatars, and contributor avatars. The ready state remains visible for one second before the loading content fades and scales away while the launcher shell rises into view

## Before launching

1. Open **Settings** and choose the interface language
2. Review the Java runtime and memory allocation
3. Select connected or autonomous identity behavior for a local profile
4. Choose or create an instance when the native instance screen becomes available
5. Start the game from Home

The bundled runtime is the safe default. A custom Java executable can be selected in settings when a compatible runtime is already installed

## Authentication

Official profiles use the Hytale authentication flow and open the system browser when interactive sign-in is required. A local profile can request its session from the configured connected service or create an autonomous OmniAuth session on the device. OmniAuth does not grant official entitlements or centralized account features

## Downloads

Version discovery checks the official source and enabled user-provided mirrors. HyPrism chooses an available source, downloads the required image or patch sequence, verifies the resulting installation, extracts assets, and launches the selected instance
