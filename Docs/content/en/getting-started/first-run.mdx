# First run

You need one player profile and one game instance before HyPrism can start Hytale

## 1. Choose the interface language

Open **Settings → General → Interface Language**. The launcher changes language immediately

## 2. Create a profile

Open **Profiles**, select **Add**, then choose a profile type

- **Official Hytale account** opens the Hytale sign-in page in your system browser and requires an entitled Hytale account
- **Offline profile** creates a local identity with a name from 3 to 16 ASCII letters, digits, hyphens, or underscores

See [Profiles](/docs/user-guide/profiles) for authentication modes and profile management

## 3. Create an instance

Open **Instances**, select **New Instance**, choose a release branch and version, then create the instance. Creating the entry does not download the game yet

See [Instances](/docs/user-guide/instances-profiles-mods) for installation, launch, and deletion behavior

## 4. Review launch settings

The defaults are suitable for most systems. Before the first download, check these options when needed

- **Settings → Java** for a custom Java executable or memory limits
- **Settings → General → Game GPU** on systems with more than one graphics adapter
- **Settings → Downloads** when you intentionally use a custom mirror
- **Settings → Network** to choose connected or autonomous sessions for offline profiles

## 5. Install and launch

Open the instance and select **Launch**. HyPrism downloads the selected version, prepares the runtime, and starts the game when installation succeeds

You can also start the current instance from [Home](/docs/user-guide/dashboard) after it has been created

:::tip
Keep the launcher open during the first installation. Hover the active instance action to reveal **Cancel** when you need to stop the download
:::
