# HyPrism Launcher

HyPrism is an unofficial open-source launcher for Hytale on Windows, Linux, and macOS. It manages separate game instances, player profiles, mods, game downloads, and launch settings

- [Install HyPrism](/docs/getting-started/installation)
- [Prepare the first launch](/docs/getting-started/first-run)
- [Manage game instances](/docs/user-guide/instances-profiles-mods)
- [Create and select profiles](/docs/user-guide/profiles)
- [Install and update mods](/docs/user-guide/mods)
- [Configure the launcher](/docs/user-guide/settings)
