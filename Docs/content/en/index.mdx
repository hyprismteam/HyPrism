# HyPrism Launcher

HyPrism is an unofficial open-source Hytale launcher built around a reusable .NET 10 core and a native Avalonia 12 desktop interface

The launcher manages game versions, instances, authentication, profiles, mods, updates, and launch preparation. The native interface provides Home, instances, profiles, news, and settings while the remaining screens receive their Avalonia implementations

## Project status

Avalonia is the only application interface. The previous launcher host and IPC generator have been removed, while native feature parity work continues for the remaining screens
