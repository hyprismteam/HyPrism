# HyPrism Launcher

HyPrism is an unofficial open-source Hytale launcher built around a reusable .NET 10 core and a native Avalonia 12 desktop interface

The launcher manages game versions, instances, authentication, profiles, mods, updates, and launch preparation. The native interface currently provides the dashboard, news reader, and settings while the remaining screens are being migrated from the obsolete Electron host

## Project status

Avalonia is the only active UI direction. The Electron project remains in the repository as a behavioral reference until native feature and packaging parity is complete
