# Avalonia migration

HyPrism moved from Electron.NET and React to a native Avalonia 12 application. The old launcher and IPC generator have been removed from the repository

## Current state

| Area | State | Notes |
| --- | --- | --- |
| Core launcher logic | active | game, user, download, version, mirror, and platform behavior lives in .NET |
| Home | native | responsive launch surface, selected-instance summary, and background selection |
| News | native | adaptive feed, full article reader, caching, rich content, and external links |
| Settings | native | adaptive categories, localization, Java memory controls, background picker, and download sources |
| Instances | native | adaptive manager with instance-scoped mods, catalog, and worlds |
| Mods | native foundation | installed content and CurseForge discovery live inside the selected instance; advanced management is still being ported |
| Profiles | pending UI | Core behavior is present, navigation currently shows a placeholder |
| Onboarding | pending UI | the native flow is not implemented yet |
| Packaging | native | release and development workflows target `HyPrism.Desktop` |

## Architectural boundary

The desktop host resolves Core components through dependency injection and calls C# interfaces directly. There is no IPC bridge or generated TypeScript contract

Historical behavior can be recovered from version control when it is still useful. New functionality belongs to `HyPrism.Core` or `HyPrism.Desktop`

## Remaining parity work

The host migration is complete. Feature parity work remains for advanced mod management, Profiles, and onboarding, and each of those workflows must be implemented directly in Avalonia
