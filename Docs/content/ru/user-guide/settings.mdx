# Настройки

Настройки используют тот же адаптивный master-detail лейаут, что и новости. В широком окне категории остаются рядом с контентом. В компактном окне показывается одна страница, а возврат работает через кнопку или Escape

## Разделы

| Раздел | Назначение |
| --- | --- |
| Общие | язык, музыка, поведение запуска, объявления и новости |
| Загрузки | запуск после установки, официальный источник и зеркала сообщества |
| Java | встроенный или пользовательский рантайм, начальная и максимальная память, дополнительные аргументы |
| Внешний вид | выбор фона и персонализация интерфейса |
| Сеть | сетевой режим, сервер авторизации и DualAuth |
| Графика | выбор предпочитаемого GPU для игры |
| Переменные | переменные окружения игрового процесса |
| Данные | каталоги приложения и экземпляров |
| О программе | информация о проекте и лицензиях |

Аргументы памяти Java, включая `-Xms` и `-Xmx`, управляются ползунками и не принимаются в свободном поле аргументов

## Источники загрузки

На странице «Загрузки» официальный источник Hytale и зеркала сообщества собраны в общей категории «Источники загрузки». Для официального источника нужен подключенный Hytale-аккаунт

Чтобы добавить зеркало сообщества, нажмите **Добавить источник**, введите его публичный HTTPS-адрес и дождитесь определения формата. После успешной проверки источник сразу станет доступен

Каждый источник сообщества можно включить, отключить или удалить. HyPrism предпочитает официальный источник и выбирает доступное включенное зеркало, когда нужен резервный источник

Добавляйте только те источники, которым вы доверяете. Обычная форма не запрашивает пользовательские заголовки авторизации и не показывает сгенерированную JSON-конфигурацию

Страница «О программе» показывает установленную версию лаунчера, последний коммит в `main`, ссылки проекта и сообщества, команду, адаптивный ряд последних контрибьюторов, лицензию исходного кода, Hytale EULA, атрибуцию визуальных материалов и дисклеймер

Настройки записываются через `IDesktopSettingsStore` и сохраняются с помощью `IConfigStore`
