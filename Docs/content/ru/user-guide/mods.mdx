# Моды

Моды принадлежат одному [экземпляру](/docs/user-guide/instances-profiles-mods). Перед управлением содержимым откройте нужный экземпляр, чтобы версия игры и каталог назначения были однозначны

## Поиск модов

1. Откройте установленный экземпляр
2. Выберите **Найти моды**
3. Выполните поиск и при необходимости измените категорию или сортировку
4. Откройте результат, чтобы проверить файлы, поддерживаемые версии, скриншоты, автора и описание
5. Выберите совместимый файл и установите его

Можно выбрать несколько совместимых результатов и запустить массовую установку. Несовместимые с текущей версией игры файлы недоступны

HyPrism получает каталог и файлы с [CurseForge](https://www.curseforge.com/hytale). Ссылка проекта открывает исходную страницу в браузере

## Импорт локальных файлов

Откройте **Установленные моды** и используйте импорт либо перетащите файлы `.jar` и `.zip` в список. HyPrism скопирует подходящие файлы в выбранный экземпляр

Импортируйте моды только из доверенных источников. Мод выполняется с правами процесса игры

## Включение, отключение и удаление

- Переключатель в строке включает или отключает один мод
- Выбор нескольких строк открывает массовое включение, отключение и удаление
- Удаление после подтверждения удаляет файл мода из экземпляра
- Поиск фильтрует установленный список по имени мода или автору

Отключенные файлы остаются в экземпляре, поэтому их можно вернуть без повторной загрузки

## Обновление модов

Нажмите **Проверить обновления**, чтобы сравнить установленные файлы CurseForge с совместимыми релизами. При наличии обновлений установите их по одному или используйте **Обновить все**

Перед крупным обновлением модов сохраните копию экземпляра, если мир зависит от них. HyPrism не гарантирует совместимость сохранений между версиями модов
