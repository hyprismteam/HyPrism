# Игры, профили и моды

В Core уже находится рабочая логика всех трех областей, но соответствующие страницы Avalonia пока не завершены

## Игры

Core умеет находить установленные экземпляры, переносить старую структуру, создавать стабильные метаданные, выбирать активный экземпляр, менять версии, импортировать ZIP-архивы и удалять установки

## Профили

Core поддерживает офлайн- и официальные профили, стабильные идентификаторы, данные отдельных профилей, переключение личности, резервные копии аватаров, восстановление скинов и хранение сессий авторизации

## Моды

Core интегрируется с CurseForge для поиска, категорий, выбора файлов, установки, импорта локальных файлов, получения списка изменений и проверки обновлений внутри экземпляра

Используйте старый Electron-интерфейс только для изучения предыдущей модели взаимодействия. Новые пользовательские функции должны появляться в `HyPrism.Desktop`
