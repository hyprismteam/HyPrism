# Игры, профили и моды

В Core находится рабочая логика всех трех областей. Нативный менеджер экземпляров уже доступен, а страницы профилей и модов еще завершаются

## Игры

Нативный менеджер экземпляров показывает локальные установки, выделяет активный экземпляр и создает цель установки с выбором ветки и доступной версии. Создание экземпляра не скачивает файлы игры сразу. После выбора используйте основное действие, чтобы скачать или запустить игру

Core также умеет переносить старую структуру, менять версии, импортировать ZIP-архивы и удалять установки

## Профили

Core поддерживает офлайн- и официальные профили, стабильные идентификаторы, данные отдельных профилей, переключение личности, резервные копии аватаров, восстановление скинов и хранение сессий авторизации

Полный список профилей хранится в `Profiles/profiles.json`. В `config.json` находится только `SelectedProfileId`, поэтому создание, выбор, переименование и удаление профиля всегда изменяют мультипрофильное хранилище, а не вторую личность лаунчера

Для запуска нужен существующий выбранный профиль с корректным именем и UUID. HyPrism не создает личность скрыто во время запуска

## Моды

Core интегрируется с CurseForge для поиска, категорий, выбора файлов, установки, импорта локальных файлов, получения списка изменений и проверки обновлений внутри экземпляра

Нативные страницы профилей и модов еще разрабатываются. При необходимости историческое поведение интерфейса можно посмотреть в истории версий
