# Главная страница

Главная страница служит нативным экраном запуска. Она показывает выбранный экземпляр поверх настроенного фона и оставляет основное действие в центре страницы

Если экземпляр не выбран, лаунчер предлагает перейти к выбору. При наличии экземпляра координатор запуска определяет версию, загружает недостающие данные, подготавливает авторизацию и ресурсы, затем запускает игровой процесс

Фон может переключаться автоматически или использовать конкретное изображение из раздела **Настройки → Внешний вид**
