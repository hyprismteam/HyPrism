# Главная страница

Главная страница служит нативным экраном запуска. Она показывает выбранный экземпляр поверх настроенного фона и собирает подготовку к запуску в одном месте

Если экземпляров нет, Главная приветствует игрока, объясняет следующий шаг и сразу предлагает создать первый экземпляр. При выборе экземпляра Главная показывает его ветку и версию, а также действия для запуска, загрузки и управления

После завершения установки HyPrism всегда автоматически запускает игру

Фон может переключаться автоматически или использовать конкретное изображение из раздела **Настройки → Внешний вид**
