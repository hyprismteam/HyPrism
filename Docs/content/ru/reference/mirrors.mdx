# Зеркала

HyPrism поддерживает официальный источник Hytale и дополнительные JSON-зеркала, добавленные пользователем

Описание зеркала содержит идентификатор, состояние, приоритет, HTTP-заголовки, сопоставление платформ, endpoint списка версий, endpoint полного образа и необязательный endpoint дифференциальных патчей

## Обнаружение

`IMirrorDiscoveryService` умеет проверить совместимый endpoint и вывести предполагаемую схему. Перед сохранением проверьте полученное описание

## Выбор во время работы

`IVersionService` загружает включенные описания, подготавливает метаданные источников, кеширует замеры скорости и выбирает доступный источник. Устаревшее значение `PreferredMirror` игнорируется, потому что выбор выполняется автоматически

## Безопасность

- используйте доверенные HTTPS-endpoint
- не добавляйте приватные заголовки авторизации в репозиторий
- считайте данные зеркала потенциально вредоносными
- не отключайте проверки целостности и безопасное извлечение
- пользовательские зеркала не отменяют требования Hytale EULA и местного законодательства

HyPrism не поставляет заранее настроенные сторонние зеркала игры
