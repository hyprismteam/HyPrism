# Зеркала

HyPrism поддерживает официальный источник Hytale и дополнительные JSON-зеркала, добавленные пользователем

Описание зеркала содержит идентификатор, состояние, приоритет, HTTP-заголовки, сопоставление платформ, endpoint списка версий, endpoint полного образа и необязательный endpoint дифференциальных патчей

## Хранение

Описания хранятся в файлах `<id>.mirror.json` в каталоге `Mirrors` внутри каталога данных приложения. `IMirrorCatalog` проверяет идентификатор и структуру схемы перед записью

Обычный UI настроек управляет этими файлами через Core и не редактирует JSON напрямую. Для сложных сценариев можно вручную добавить совместимое описание

## Обнаружение и UI

`IMirrorDiscovery` проверяет публичный HTTPS-endpoint и выводит предполагаемую схему. Desktop проверяет адрес, отклоняет дубликаты endpoint, назначает уникальный локальный идентификатор, сохраняет описание через `IMirrorCatalog` и перезагружает рабочие источники

Обычный HTTP разрешен только для loopback-адресов, нужных при локальной разработке

## Выбор во время работы

`IGameVersionCatalog` загружает включенные описания, подготавливает метаданные источников, кеширует замеры скорости и выбирает доступный источник. Включение, отключение, добавление или удаление зеркала обновляет рабочий список без перезапуска лаунчера

`ProbeSourceAvailabilityAsync` измеряет задержку endpoint без загрузки игровых payload. Проверка зеркала также читает метаданные release и pre-release для текущей платформы. Проверка официального источника использует действующую сессию любого официального профиля, обращается к авторизованному patches API и сообщает о доступности только при наличии загрузки для текущей платформы. Desktop запускает эти проверки один раз при первом открытии таблицы и сохраняет результаты при навигации между категориями

Устаревшее значение `PreferredMirror` игнорируется, потому что выбор выполняется автоматически

## Безопасность

- используйте доверенные HTTPS-endpoint
- не добавляйте приватные заголовки авторизации в репозиторий
- считайте данные зеркала потенциально вредоносными
- не отключайте проверки целостности и безопасное извлечение
- пользовательские зеркала не отменяют требования Hytale EULA и местного законодательства

HyPrism не поставляет заранее настроенные сторонние зеркала игры
