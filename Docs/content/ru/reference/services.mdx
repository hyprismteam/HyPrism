# Контракты Core

`Bootstrapper.Initialize` регистрирует стандартные реализации и возвращает `IServiceProvider`. Хост может добавить платформенные регистрации через callback конфигурации

Desktop читает версию лаунчера, сгенерированную из `HyPrism.Desktop.csproj`, и настраивает общую HTTP-идентификацию при запуске. Запросы новостей, среды выполнения, GitHub и DualAuth используют `HyPrism/<версия>` без отдельно поддерживаемой константы версии

| Область | Основные контракты | Ответственность |
| --- | --- | --- |
| Конфигурация | `IConfigStore` | сохранение общей конфигурации лаунчера и игры |
| Прогресс | `IProgressReporter` | троттлируемые события прогресса и ошибок, привязанные к операции экземпляра |
| Версии | `IGameVersionCatalog`, `IVersionSource`, `IMirrorCatalog`, `IMirrorDiscovery` | списки версий, выбор источников, хранение и обнаружение зеркал, кеш и патчи |
| Экземпляры | `IInstanceRepository`, `IInstanceMigrator` | пути, метаданные, сохраняемый порядок, выбор, импорт, миграция и уведомления `InstancesChanged` |
| Загрузка | `IFileDownloader`, `IPatchManager`, `IButlerClient` | передача, проверка файлов, патчинг и Butler |
| Runtime | `IRuntimeProvisioner` | отменяемая установка JRE и Visual C++, поиск runtime и проверка совместимости |
| Запуск | `IGameInstallationWorkflow`, `IGameLaunchCoordinator`, `IGameLauncher` | путь от выбранного или явно указанного экземпляра до процесса игры; координатор поднимает `LaunchFailed`, когда попытка завершилась без запущенного процесса |
| Процесс | `IGameProcessTracker` | постоянное отслеживание процессов, типизированные события, сверка после простоя и корректное завершение конкретного экземпляра |
| Моды | `IModManager` | поиск, установка, импорт, обновления и changelog |
| Авторизация | `IHytaleAuthenticator`, `IOAuthCallbackPageRenderer`, `GameSessionAuthenticator` | официальные сессии, OAuth-запросы, страницы callback от хоста и игровые токены |
| Профили | `IProfileManager`, `IProfileRepository`, `IUserIdentityProvider` | личность, сохраняемый порядок, жизненный цикл профиля и уведомления `ProfilesChanged` |
| Ресурсы | `IAvatarCache`, `ISkinRepository` | данные аватаров и скинов для профилей и запуска игры |
| Платформа | `IGpuProvider` | определение GPU, необходимое кроссплатформенному запуску игры |
| Presence | `IDiscordPresence` | обновление состояния лаунчера и игры через реализацию хоста |

Контракты находятся рядом с реализацией своей функциональности. В `Application/Ports` лежат только возможности, которые предоставляет активный хост, сейчас это `IDiscordPresence` и `IGpuProvider`

Запрашивайте самый узкий контракт, необходимый потребителю. Не получайте зависимости из контейнера внутри доменного кода

Интерактивный OAuth не зависит от браузерного сервиса в Core. Хост передает асинхронную функцию открытия URI в операцию запуска, а Core вызывает ее только тогда, когда официальному аккаунту требуется авторизация. Хост может зарегистрировать `IOAuthCallbackPageRenderer`, чтобы заменить минимальный резервный HTML локального обработчика callback

В контрактах долгих операций `CancellationToken` располагается последним. Установка передает отмену в загрузки runtime и Butler, запись файлов, распаковку архивов и ожидание процессов. Импорт ZIP-экземпляра и поиск официальной сессии также учитывают отмену в асинхронных файловых и HTTP-операциях

Настройки Avalonia предоставляет `IDesktopSettingsStore` из `HyPrism.Desktop`. Компоненты Core, которым нужны параметры запуска, используют `IConfigStore` напрямую

`IHytaleNewsClient`, `IGitHubClient` и их реализации принадлежат функциональности Desktop. Новости предоставляют только официальную ленту Hytale и структурированные статьи, а данные GitHub используются страницей «О программе»
