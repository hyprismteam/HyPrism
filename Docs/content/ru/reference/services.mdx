# Контракты Core

`Bootstrapper.Initialize` регистрирует стандартные реализации и возвращает `IServiceProvider`. Хост может добавить платформенные регистрации через callback конфигурации

| Область | Основные контракты | Ответственность |
| --- | --- | --- |
| Конфигурация | `IConfigStore` | сохранение общей конфигурации лаунчера и игры |
| Прогресс | `IProgressReporter` | события загрузки, состояния игры и ошибок |
| Версии | `IGameVersionCatalog`, `IVersionSource`, `IMirrorCatalog`, `IMirrorDiscovery` | списки версий, выбор источников, хранение и обнаружение зеркал, кеш и патчи |
| Экземпляры | `IInstanceRepository`, `IInstanceMigrator` | пути, метаданные, выбор, импорт и миграция |
| Загрузка | `IFileDownloader`, `IPatchManager`, `IButlerClient` | передача, проверка файлов, патчинг и Butler |
| Запуск | `IGameInstallationWorkflow`, `IGameLaunchCoordinator`, `IGameLauncher` | путь от выбранного экземпляра до процесса игры |
| Процесс | `IGameProcessTracker` | отслеживание и корректное завершение процесса |
| Моды | `IModManager` | поиск, установка, импорт, обновления и changelog |
| Авторизация | `IHytaleAuthenticator`, `GameSessionAuthenticator` | официальные сессии, OAuth-запросы и игровые токены |
| Профили | `IProfileManager`, `IProfileRepository`, `IUserIdentityProvider` | жизненный цикл личности и профиля |
| Ресурсы | `IAvatarCache`, `ISkinRepository` | данные аватаров и скинов для профилей и запуска игры |
| Платформа | `IGpuProvider` | определение GPU, необходимое кроссплатформенному запуску игры |
| Presence | `IDiscordPresence` | обновление состояния лаунчера и игры через реализацию хоста |

Контракты находятся рядом с реализацией своей функциональности. В `Application/Ports` лежат только возможности, которые предоставляет активный хост, сейчас это `IDiscordPresence` и `IGpuProvider`

Запрашивайте самый узкий контракт, необходимый потребителю. Не получайте зависимости из контейнера внутри доменного кода

Интерактивный OAuth не зависит от браузерного сервиса в Core. Хост передает асинхронную функцию открытия URI в операцию запуска, а Core вызывает ее только тогда, когда официальному аккаунту требуется авторизация

Настройки Avalonia предоставляет `IDesktopSettingsStore` из `HyPrism.Desktop`. Компоненты Core, которым нужны параметры запуска, используют `IConfigStore` напрямую

`IHytaleNewsClient`, `IGitHubClient` и их реализации принадлежат функциональности Desktop. Новости предоставляют только официальную ленту Hytale и структурированные статьи, а данные GitHub используются страницей «О программе»
