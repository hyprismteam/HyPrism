# Справочник конфигурации

`ConfigService` читает и сохраняет модель `Config` в `config.json`

## Личность и выбор

| Ключ | Значение |
| --- | --- |
| `UUID` и `Nick` | текущая офлайн-личность |
| `SelectedProfileId` | стабильный идентификатор активного профиля |
| `SelectedInstanceId` | стабильный идентификатор активного экземпляра |
| `OnlineMode` | официальная сетевая авторизация при включении |
| `AuthDomain` | домен сервера авторизации для совместимых режимов запуска |

## Запуск и Java

| Ключ | Значение |
| --- | --- |
| `CloseAfterLaunch` | закрывать HyPrism после успешного запуска игры |
| `LaunchAfterDownload` | запускать игру после завершения установки |
| `UseCustomJava` | использовать выбранный пользователем Java executable |
| `CustomJavaPath` | абсолютный путь к executable |
| `JavaArguments` | дополнительные JVM-опции и управляемые аргументы памяти |
| `GpuPreference` | `dedicated`, `integrated` или `auto` |
| `GameEnvironmentVariables` | строки `KEY=VALUE`, разделенные переносом |
| `UseDualAuth` | использовать Java agent DualAuth |

## Интерфейс и данные

| Ключ | Значение |
| --- | --- |
| `Language` | культура, например `en-US` или `ru-RU` |
| `MusicEnabled` | состояние фоновой музыки |
| `BackgroundMode` | `auto` или имя встроенного фона |
| `DisableNews` | не загружать и не показывать новости |
| `ShowDiscordAnnouncements` | показывать поддерживаемые объявления |
| `DismissedAnnouncementIds` | скрытые пользователем идентификаторы объявлений |
| `InstanceDirectory` | пользовательский корень экземпляров |
| `ShowAlphaMods` | показывать alpha-файлы модов в поиске |

Поля с атрибутом obsolete нужны только для чтения и миграции старой конфигурации. Новый код должен использовать стабильные идентификаторы профилей и экземпляров
