# HyPrism.Core

`HyPrism.Core` владеет поведением, которое не должно зависеть от UI-фреймворка

## Приложение и инфраструктура

- `Core/App` содержит настройки, обновления, распаковку пакетов и уведомления о прогрессе
- `Core/Infrastructure` содержит конфигурацию, файлы, логи, информацию о системе и общие утилиты
- `Core/Integration` содержит новости, GitHub, Discord Rich Presence и помощники удаленных протоколов
- `Core/Platform` содержит оставшиеся границы буфера обмена, файловых диалогов и определения GPU

## Игра

- `Game/Version` получает метаданные версий из официального источника и зеркал
- `Game/Download` загружает файлы, применяет патчи и сообщает прогресс
- `Game/Instance` управляет метаданными, путями, выбором, импортом, удалением и миграциями экземпляров
- `Game/Launch` подготавливает Java, авторизацию, патчинг, окружение и игровой процесс
- `Game/Asset` извлекает ресурсы и защищает данные аватаров
- `Game/Mod` ищет и устанавливает моды CurseForge или локальные файлы
- `Game/Sources` реализует официальный источник и JSON-зеркала

## Пользователь

`User` отвечает за авторизацию Hytale, профили, личности, токены, скины и перенос старых данных профилей

## Правило зависимостей

Core может предоставлять возможности хоста через интерфейсы, но не должен ссылаться на Avalonia, Electron или модели представления

OAuth остается независимым от UI: Core формирует URI авторизации и принимает callback хоста для его показа. Открытием браузера владеет активный хост приложения
