# HyPrism.Desktop

Desktop служит хостом приложения Avalonia. Он собирает сервисы Core, предоставляет системные возможности и преобразует их состояние в представления и команды

## Композиция и функции

| Расположение | Ответственность |
| --- | --- |
| `Program.cs` | Регистрации сервисов, рендерер, точка входа |
| `App.axaml` и `App.axaml.cs` | Ресурсы, создание окна, запуск и завершение |
| `Shell` | Окно, навигация, общее состояние, координация экземпляров и новостей |
| `Features/Dashboard` | Запуск текущего экземпляра |
| `Features/Instances` | Экземпляры, моды, каталог, миры и консоль |
| `Features/Profiles` | Карточки, активация, редактирование, создание и вход |
| `Features/Settings` | Настройки, адаптер хранения, использование диска |
| `Features/News` | Официальная лента, разбор HTML, статьи, форматированный текст |
| `Features/About` | Репозиторий GitHub, коммиты, участники и аватары |
| `Platform` | Ссылки, папки, диалоги, память, GPU, кэш изображений |
| `Integrations/Discord` | Реализация контракта presence |
| `Localization` | Строковые ресурсы и переключение языка |

## Представления и состояние

В проекте включены компилируемые привязки. Представления объявляют `x:DataType`, модели предоставляют наблюдаемое состояние и команды. Code-behind обрабатывает ввод, компоновку, фокус и анимацию

Пример привязки к существующей модели настроек

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:settings="using:HyPrism.Desktop.Features.Settings"
             x:DataType="settings:SettingsViewModel">
  <ToggleSwitch IsChecked="{Binding CloseAfterLaunch}" />
</UserControl>
```

Изменения наблюдаемых коллекций публикуются через UI dispatcher. При освобождении владельца нужно отписаться от событий сервисов и освободить изображения

## Общая основа UI

`Styles/Tokens.axaml` определяет цвета и семантические токены, а `Styles/Controls.axaml` общие стили. Используйте их классы вместо копирования вариантов в отдельные функции

| Элемент | Ответственность |
| --- | --- |
| `AdaptiveMasterDetailHost` | Общая широкая и компактная навигация |
| `DeferredContentControl` | Отложенное создание и сохранение представлений |
| `WizardHost` | Состояние мастера, переходы и координация навигации |
| `OverlayModal` | Общая панель диалога |
| `FadingPopup` и `FadingComboBox` | Жизненный цикл всплывающих меню |
| `ReorderableListController` | Маркеры перетаскивания, превью и позиции |
| `NoteCard` | Информационные и важные примечания |
| `SmoothScrollViewer` | Прокрутка колесом и средней кнопкой |

Длительности анимации принадлежат `MotionDurations` или общему элементу-владельцу. Проверки компоновки и рендеринга описаны в [руководстве по производительности](/docs/development/avalonia-performance)

## Сетевое содержимое

Клиенты новостей и GitHub используют общую HTTP-идентификацию. Разобранные новости хранятся в `Cache/News`, закодированные изображения в `Cache/Images`. Текст статьи готовится до декодирования изображений, а декодированные bitmap освобождаются при закрытии статьи

Выбор файлов использует Avalonia `StorageProvider`. Обработчик ссылок сохраняет экранированные абсолютные URI, включая параметры OAuth. Эти возможности не принадлежат Core
