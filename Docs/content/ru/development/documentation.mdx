# Сайт документации

Документация представляет собой приложение Nextra 4, полностью расположенное в каталоге `Docs`

## Локальная разработка

Используйте Node.js 22 и pnpm 11.21.0. Поле `packageManager` в `Docs/package.json` синхронизирует версию pnpm в локальной среде и CI

```bash
cd Docs
pnpm install
pnpm dev
```

Откройте `http://localhost:3000/HyPrism/docs/`. Локальный dev-сервер использует тот же base path `/HyPrism`, что и GitHub Pages

## Модель локализации

Английские страницы находятся в `content/en`, русские в `content/ru`, а маршруты в обоих деревьях должны совпадать. Обе версии экспортируются под одним URL `/docs`

Переводы поиска, навигационных элементов, тем, оглавления и footer хранятся в `app/_dictionaries`. Переключатель меняет язык без смены URL и сохраняет выбор в браузере

Команды `dev`, `check` и `build` генерируют `app/_components/mdx-registry.generated.ts` из обоих языковых деревьев. Добавляйте парные MDX-файлы и не редактируйте сгенерированный реестр вручную. Генерация завершается с ошибкой, если маршрут отсутствует в одном из языков

## Production-сборка

```bash
cd Docs
pnpm install --frozen-lockfile
pnpm check
pnpm build
```

Next.js экспортирует статические файлы в `Docs/out`

## Путь GitHub Pages

Workflow задает `PAGES_BASE_PATH=/HyPrism`. Документация будет доступна по адресу

```text
https://hyprismteam.github.io/HyPrism/docs/
```

Сайт выбирает английскую или русскую версию по сохраненному выбору и языку браузера

В настройках репозитория откройте **Pages** и выберите **GitHub Actions** как источник публикации. Остальную сборку и развертывание выполняет `docs-pages.yml`
