# Тестирование

Запускайте тесты из корня репозитория. Каждый набор имеет отдельный проект и матрицу CI

```bash
dotnet test Tests/HyPrism.Core.Tests/HyPrism.Core.Tests.csproj
dotnet test Tests/HyPrism.LocalNode.Tests/HyPrism.LocalNode.Tests.csproj
dotnet test Tests/HyPrism.Desktop.Tests/HyPrism.Desktop.Tests.csproj
```

## Границы покрытия

| Набор | Основное покрытие |
| --- | --- |
| Core | Координация запуска, процессы, профили, загрузки, конфигурация, зеркала, патчи, моды |
| Local Node | HTTPS, токены, хранение аккаунтов, сертификаты, жизненный цикл процесса |
| Desktop | Модели представления, локализация, платформенные адаптеры, рендеринг и элементы UI |

Тесты Local Node закрепляют созданные сертификаты и отключают системные изменения доверия. Модульные тесты используют временные данные и mock-сервисы вместо живых аккаунтов, игры и внешних API

Тесты Desktop разделяют приложение Avalonia, dispatcher и композитор, поэтому выполняются последовательно. Ожидайте итоговое свойство или состояние; фиксированная задержка подходит только для намеренного снимка промежуточного кадра

## Запуск конкретных тестов

При разработке используйте фильтр полного имени

```bash
dotnet test Tests/HyPrism.Desktop.Tests/HyPrism.Desktop.Tests.csproj \
  --filter FullyQualifiedName~StringLocalizerTests
```

Создание скриншотов запускается отдельно по инструкции [сайта документации](/docs/development/documentation#screenshots). Обычный запуск тестов пропускает съемку

## CI и ручные проверки

Core, Desktop и Local Node отдельно запускаются в Ubuntu, Windows и macOS с `fail-fast: false`. Упаковка образует отдельную группу

Workflow Local Node для macOS также публикует apphost и проверяет HTTPS health с созданным центром в одноразовой связке ключей runner. Это не проверяет интерактивный запрос доверия на компьютере игрока или полноценный запуск Hytale

При изменении соответствующей границы проверяйте системный композитор, диалоги и совместимость с игрой вручную. Для изменения документации выполняйте [проверку контента и статический экспорт](/docs/development/documentation)
