# Тестирование

Запустите активные тесты из корня репозитория

```bash
dotnet test Tests/HyPrism.Core.Tests/HyPrism.Core.Tests.csproj
dotnet test Tests/HyPrism.Desktop.Tests/HyPrism.Desktop.Tests.csproj
```

Тесты Core проверяют координацию запуска и работу профилей. Desktop-тесты используют Avalonia Headless для проверки локализации и важных состояний окна

## Границы тестов

- проверяйте доменное поведение через интерфейсы Core
- используйте временные каталоги для постоянного состояния
- не обращайтесь к реальной авторизации, игре или сторонним API в unit-тестах
- добавляйте регрессионный тест при исправлении воспроизводимой ошибки
- делайте render-тесты независимыми от системной темы

После изменения страниц, навигации или конфигурации Docusaurus запускайте сборку документации
