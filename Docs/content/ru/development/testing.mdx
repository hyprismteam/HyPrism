# Тестирование

Запустите активные тесты из корня репозитория

```bash
dotnet test Tests/HyPrism.Core.Tests/HyPrism.Core.Tests.csproj
dotnet test Tests/HyPrism.LocalNode.Tests/HyPrism.LocalNode.Tests.csproj
dotnet test Tests/HyPrism.Desktop.Tests/HyPrism.Desktop.Tests.csproj
```

Тесты Core проверяют координацию запуска и работу профилей. Тесты протокола, постоянного состояния, сертификатов, HTTPS и процессов Local Node находятся в `HyPrism.LocalNode.Tests`. Их HTTPS-клиенты используют pinning созданного сертификата и отключают изменения системного доверия, поэтому запуск набора не добавляет временные центры сертификации в root store Windows и не показывает запросы доверия. Desktop-тесты используют Avalonia Headless для проверки локализации и важных состояний окна

CI показывает Core, Desktop, Local Node и Packaging как отдельные верхнеуровневые группы checks. Наборы Core, Desktop и Local Node запускаются в Ubuntu, Windows и macOS через отдельные reusable workflows. Matrix jobs используют `fail-fast: false`, поэтому ошибка одной платформы не скрывает результаты остальных систем. Desktop покрывается headless-тестами, которые проверяют Avalonia-приложение в каждой операционной системе без открытия окна через нативный compositor. Платформенные packaging workflows отдельно публикуют нативные артефакты

Desktop-тесты выполняются последовательно, потому что Avalonia application, dispatcher и compositor являются общим состоянием процесса. Render-тесты должны ждать наблюдаемого конечного свойства или состояния view model, а не считать фиксированную задержку доказательством завершения анимации. Фиксированная задержка допустима только когда тест намеренно снимает промежуточный кадр анимации

Группа Local Node для macOS также публикует apphost Desktop и Local Node для `osx-arm64` и обращается к endpoint `/health` после регистрации корневого сертификата `hyprism-local-ca.crt` в одноразовом System Keychain runner. Smoke-тест проверяет выпущенный этим корнем серверный сертификат `127.0.0.1`, статус `ready`, ожидаемое имя сервера и HTTPS issuer Local Node. Детерминированные тесты проверяют production-последовательность команд user Keychain, включая проверку имени хоста и ротацию сертификата. CI не может подтвердить интерактивный диалог безопасности пользователя или заменить финальный запуск с установленным клиентом Hytale на физическом Mac

## Границы тестов

- проверяйте доменное поведение через интерфейсы Core
- используйте временные каталоги для постоянного состояния
- не обращайтесь к реальной авторизации, игре или сторонним API в unit-тестах
- добавляйте регрессионный тест при исправлении воспроизводимой ошибки
- делайте render-тесты независимыми от системной темы
- ждите конечного состояния UI вместо предположения о длительности анимации

После изменения страниц, навигации или конфигурации Docusaurus запускайте сборку документации
