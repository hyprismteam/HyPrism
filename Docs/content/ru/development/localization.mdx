# Локализация

Локализация принадлежит `HyPrism.Desktop`, потому что перевод текста интерфейса является задачей слоя представления

Ресурс по умолчанию находится в `Sources/HyPrism.Desktop/Localization/Resources.resx`. Для каждой культуры существует соседний файл, например `Resources.ru-RU.resx`

## Добавление строки

1. Добавьте ключ и английское значение в `Resources.resx`
2. Добавьте тот же ключ во все файлы культур
3. Получайте значение через `LocalizationService`
4. Обновляйте затронутую view model после события `LanguageChanged`
5. Добавьте или обновите тесты локализации

`_supportedCultures` в ресурсе по умолчанию управляет списком языков. `_langName` в файле каждой культуры задает локальное название

Core хранит только код выбранной культуры через `ISettingsService`. Переведенные строки и Avalonia resource lookup не должны находиться в Core
