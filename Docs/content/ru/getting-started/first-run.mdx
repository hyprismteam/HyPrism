# Первый запуск

При старте HyPrism показывает экран загрузки с однотонным фоном, расположенный как страница успешной авторизации официального аккаунта. В центральной области статуса воспроизводится компактная зацикленная Lottie-анимация с маской прозрачности, текущую операцию сопровождают точки акцентного цвета темы, а логотип лаунчера остается внизу. В это время HyPrism создает каталог приложения, читает `config.json`, переносит поддерживаемые старые данные, регистрирует сервисы и заранее загружает ленту и превью новостей Hytale, а также аватары команды и контрибьюторов. Состояние готовности остается на экране одну секунду, после чего контент загрузки плавно уменьшается и исчезает, а основной интерфейс появляется с подъемом

## Перед запуском игры

1. Откройте **Настройки** и выберите язык интерфейса
2. Проверьте Java-рантайм и выделение памяти
3. Выберите сетевой или автономный режим для локального профиля
4. Выберите или создайте экземпляр после появления нативного экрана экземпляров
5. Запустите игру с главной страницы

Встроенный рантайм подходит для большинства случаев. Пользовательский исполняемый файл Java можно выбрать в настройках, если совместимая версия уже установлена

## Авторизация

Официальные профили используют процесс авторизации Hytale и открывают системный браузер, когда нужен интерактивный вход. Локальный профиль может получить сессию у настроенного сетевого сервиса или создать автономную OmniAuth-сессию на устройстве. OmniAuth не дает официальных прав и доступа к централизованным функциям аккаунта

## Загрузки

Поиск версий проверяет официальный источник и включенные пользовательские зеркала. HyPrism выбирает доступный источник, загружает полный образ или цепочку патчей, проверяет установку, извлекает ресурсы и запускает выбранный экземпляр
