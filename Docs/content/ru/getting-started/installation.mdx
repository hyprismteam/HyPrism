# Установка

## Готовые сборки

Скачайте сборку для своей платформы со страницы [GitHub Releases](https://github.com/hyprismteam/HyPrism/releases)

| Платформа | Текущая архитектура | Форматы |
| --- | --- | --- |
| Windows | x64 | портативный ZIP |
| Linux | x64 | tar.xz |
| macOS | Apple Silicon | DMG |

Релизные пакеты содержат нативное Avalonia-приложение Desktop и apphost Local Node, необходимый для автономной авторизации

## Запуск нативного проекта

Установите .NET 10 SDK, клонируйте репозиторий и выполните

```bash
dotnet restore HyPrism.sln
dotnet run --project Sources/HyPrism.Desktop/HyPrism.Desktop.csproj
```

Desktop-проект напрямую ссылается на `HyPrism.Core` и не требует Node.js

## Локальные данные

HyPrism определяет доступный для записи каталог приложения во время запуска. В нем хранятся конфигурация, профили, экземпляры, кеши, логи, зеркала и загруженные вспомогательные инструменты

Перед проверкой миграций на существующей установке создайте резервную копию каталога приложения
