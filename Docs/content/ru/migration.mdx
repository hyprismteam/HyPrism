# Переход на Avalonia

HyPrism переходит с Electron.NET и React на нативный интерфейс Avalonia 12. Логика лаунчера остается на .NET 10 и переиспользуется через `HyPrism.Core`

## Текущее состояние

| Область | Состояние | Подробности |
| --- | --- | --- |
| Логика Core | сохранена | сервисы игры, пользователя, загрузки, версий, зеркал и платформы остаются на .NET |
| Главная | нативная | адаптивный экран запуска и выбор фона |
| Новости | нативные | адаптивная лента, полные статьи, кеширование, rich content и внешние ссылки |
| Настройки | нативные | адаптивные категории, локализация, память Java и выбор фона |
| Игры | ожидает UI | сервисы Core готовы, пункт навигации пока открывает заглушку |
| Моды | ожидают UI | сервисы Core готовы, пункт навигации пока открывает заглушку |
| Профили | ожидают UI | сервисы Core готовы, пункт навигации пока открывает заглушку |
| Онбординг | ожидает UI | старый сценарий еще не заменен |
| Упаковка | переходная | релизные скрипты пока содержат Electron-пути и инструменты |

## Граница архитектуры

Нативный хост получает сервисы Core через dependency injection и напрямую вызывает C#-интерфейсы. Electron IPC и сгенерированный `ipc.ts` ему не нужны

`HyPrism.Launcher`, React-фронтенд и `HyPrism.IpcGen` являются устаревшими эталонами для переноса. Новые продуктовые функции в них не добавляются

## Условие завершения

Перенос считается завершенным, когда каждый пользовательский сценарий имеет нативную страницу, релизная упаковка запускает Avalonia-хост на всех платформах, критические сценарии покрыты тестами, а runtime-пути не зависят от Electron и TypeScript-моста
