# Переход на Avalonia

HyPrism перешел с Electron.NET и React на нативное приложение Avalonia 12. Старый лаунчер и генератор IPC удалены из репозитория

## Текущее состояние

| Область | Состояние | Подробности |
| --- | --- | --- |
| Логика Core | активна | игра, пользователь, загрузки, версии, зеркала и платформенное поведение живут в .NET |
| Главная | нативная | адаптивный экран запуска и выбор фона |
| Новости | нативные | адаптивная лента, полные статьи, кеширование, rich content и внешние ссылки |
| Настройки | нативные | адаптивные категории, локализация, память Java, выбор фона и источники загрузки |
| Экземпляры | нативные | адаптивный менеджер с модами, каталогом, мирами и живой консолью выбранного экземпляра |
| Моды | нативные | менеджер установленных модов с иконками, переключателями, выделением, массовыми действиями, проверкой обновлений, локальным импортом и drag-and-drop; каталог CurseForge с фильтрами категории и сортировки, бесконечной прокруткой, массовой установкой с учетом совместимости и модальным просмотром файлов и версий |
| Профили | нативные | адаптивный менеджер сохраненных профилей, создание офлайн-профилей, вход Hytale, редактирование, дублирование, удаление, папки и копирование UUID |
| Онбординг | ожидает UI | нативный сценарий еще не реализован |
| Упаковка | нативная | релизные и dev-сценарии нацелены на `HyPrism.Desktop` |

## Граница архитектуры

Хост Desktop получает компоненты Core через dependency injection и напрямую вызывает C#-интерфейсы. IPC-моста и генерируемого TypeScript-контракта больше нет

Историческое поведение при необходимости можно извлечь из истории версий. Новая функциональность принадлежит `HyPrism.Core` или `HyPrism.Desktop`

## Оставшаяся работа

Перенос хоста завершен. Работа над функциональным паритетом осталась для просмотрщика логов экземпляра и онбординга, и каждый из этих сценариев должен быть реализован сразу в Avalonia
